# Amplife® Policy Archive (Mirror)

This repository is a public mirror of the Amplife® Policy Archive. It holds the current text of every published Amplife® policy and a tagged change log for each one, so anyone can verify our terms and how they have changed over time.

The canonical archive lives at https://www.amplife.co/policy-archive. If anything in this repository conflicts with the policies published on amplife.co, the published policy text controls. This mirror is provided for transparency and reference convenience only; it does not modify, supplement, or interpret any policy.

## How it works

- `policies/` holds the current text of each policy.
- `changelogs/` holds the change log for each policy, newest version first, with each change tagged (for example [PROTECTS CUSTOMERS], [CLARIFIED], [MECHANICS]).
- Every future change to a policy is committed here with the change log entry as the commit message, so the commit history shows the exact line-by-line difference of every change ever made.
