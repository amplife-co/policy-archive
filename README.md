# Amplife® Policy Archive (Mirror)

This repository is a public mirror of the Amplife® Policy Archive. It holds the current text of the Amplife® policies published in this repository, together with a tagged change log for each one, so anyone can verify our terms and how they have changed over time.

The canonical archive lives at https://www.amplife.co/pages/policy-archive. If anything in this repository conflicts with the policies published on amplife.co, the published policy text controls. This mirror is provided for transparency and reference convenience only; it does not modify, supplement, or interpret any policy.

## How it works

- `policies/` holds the text of each policy in this repository, current as of the most recent commit.
- `changelogs/` holds the change log for each policy, newest version first, with each change tagged (for example [PROTECTS CUSTOMERS], [CLARIFIED], [MECHANICS]). The full tag legend is published on the archive page at amplife.co.
- Every change to a policy in this repository from July 23, 2026 forward is committed here with the change log entry as the commit message, so the commit history shows the exact line-by-line difference of each change. Versions published before that date are documented in the change logs and in the archived PDFs at amplife.co.
- Each policy carries a "Last Updated" date at the top of the file, written with an ordinal day, for example March 23rd, 2022. Change log version headers use a cardinal date for the same day, for example Version dated March 23, 2022. Both refer to the same published version.
- The newest change log entry always corresponds to the "Last Updated" date on its policy. Where a date changed without any change in terms, the entry records the date change and confirms that no term was changed.
